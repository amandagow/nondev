GitHub is a platform where teams work together to plan, track, review, and deliver work. It helps organizations coordinate ideas, updates, and decisions in one place, whether the work involves product improvements, bug fixes, documentation, or cross-team initiatives.

Even if you are not writing code, GitHub can help you stay connected to project progress, give feedback, and collaborate with technical and non-technical teammates. It is used by millions of people and organizations around the world to manage work transparently and efficiently.

In this module, you’ll learn the basics of GitHub and build a practical understanding of its core features through a hands-on exercise inside a GitHub repository.

## Learning objectives

In this module, you’ll:

- Identify the core features of GitHub and how they support team collaboration.
- Learn the basics of repository management (a repository is a shared workspace for project files, updates, and history).
- Understand the GitHub flow, including branches, commits, and pull requests, as a structured way teams propose, review, and approve changes.
- Explore collaboration tools such as issues and discussions to track tasks, questions, and decisions.
- Recognize how to manage notifications and subscriptions so you can stay informed without being overwhelmed.


## Prerequisites

- A GitHub account
